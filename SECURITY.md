# Security policy

## Reporting a repository vulnerability

Please use GitHub's private vulnerability-reporting or security-advisory feature for vulnerabilities in Censpy itself. Include the affected component, reproduction conditions, impact, and a minimal proof of concept that uses synthetic data or a system you control.

Do not include third-party credentials, browser profiles, customer data, live target details, or assessment evidence in an issue or pull request.

## Scope

This policy covers defects in the source code and documented setup in this repository. It does not authorize testing Censys, Nmap, `nrich`, GitHub, or any third-party system. It is not a bug-bounty program and no reward is promised.

## Supported version

The latest commit on the default branch is the only supported version of this portfolio project.
