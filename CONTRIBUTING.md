# Contributing

Thanks for helping improve Censpy. Keep contributions small, reviewable, and safe to reproduce.

## Before opening a pull request

1. Open an issue describing the problem or proposed behavior.
2. Use only synthetic inputs, documentation-only IP ranges, or systems you own.
3. Never commit credentials, browser state, target lists, screenshots, or scan output.
4. Run `python -m unittest discover -s tests -v`.
5. Explain behavioral and output-schema changes in the pull request.

Contributions that weaken authorization safeguards, evade provider controls, or include third-party assessment data will not be accepted.
